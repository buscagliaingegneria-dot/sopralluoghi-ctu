Photoshop Automation from Revit

Claude cuts a 3D view of your Revit model at the height you pick and exports it as masks: one colour for each kind of thing, the sun, the lines and the cut. Photoshop builds the picture from those masks, one named layer at a time, with a material on each floor.

Shown on the Pacific Continental Residence in Revit 2027

1. Connect Revit

The prompt runs through the Revit MCP server, a free add-in that lets Claude read the model you have open and make changes in it. Set it up once and it loads with Revit after that.

▸How to set up the Revit MCPopen

The full setup, with a video, is at archaiflow.com/setup.

step 1Install pyRevit

Install the latest pyRevit from pyrevitlabs.io.

step 2Add the extension, in Revit

It is in pyRevit’s own extension list, so there is nothing to download by hand.

  1. 1.Revit → pyRevit tab → Extensions. Find revit-mcp-python and install it.
  2. 2.Same tab → Settings → Routes: turn the Routes Server on.
  3. 3.Restart Revit and open a project.

step 3Install the Revit MCP

Paste this prompt to install the Revit MCP.

Quitting Claude Desktop completely and reopening it puts Revit Connector in the connectors list under the message box.

2. Connect Adobe

Adobe is a published connector, so there is nothing to install. In Claude, open the + menu under the message box, then Connectors → Add connector → Browse connectors, and connect Adobe.

3. One prompt

This prompt is for an axo cut from a Revit 3D view. Open the model in Revit and open Photoshop, then paste it into a new chat.

Claude asks one question at a time and waits for each answer. After the last one, the rest runs on its own.

The four lines under “While you work” are what took longest to find out. With them, the masks line up and the cut is Revit’s own.

4. What comes back

The view is a copy of a 3D view, cut by a section box at 4′-6″, so you look into every room from above.

Then the same view four more times, with the same crop, so every pixel lines up.

Then Photoshop builds the picture from those masks. It comes back as a layered PSD and a PNG.

Every step is its own named layer with its Revit mask: the model in sun and the lawn, then a Floors group with oak, bath tile, kitchen porcelain, entry terrazzo and court pavers, then a Build group with the cut walls, the cut soil, glass, doors and the Revit lines, then a last pass on the tones.

The floor textures are free ones from ambientCG.

5. Why from the masks

Photoshop never guesses where a wall or a floor is. Every shape comes from a Revit mask, so walls, floors, doors and glass land where the model has them.

The dark wall tops are Revit’s own cut, so they sit exactly where the section box cuts the walls.

And because each part is its own layer with its own mask, you can change one material or one colour in Photoshop and leave the rest as it is.
